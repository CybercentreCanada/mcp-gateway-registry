2. Ruff is a fast Python linter and formatter. It checks your code for style issues, potential errors, and formatting inconsistencies. The `ruff check` command analyzes the code for issues, while `ruff format --check` checks if the code adheres to the formatting rules without making changes. If any issues are found, you can use `ruff format` to automatically fix them.

```bash
$ echo "=== ruff check ===" && uv run ruff check registry/auth/dependencies.py 2>&1

$ echo "=== ruff format (check mode) ===" && uv run ruff format --check registry/auth/dependencies.py 2>&1

$ echo "=== trailing whitespace on changed files ===" && grep -rn " $" \
  charts/mongodb-configure/templates/configmap.yaml \
  cli/examples/trinity-power-users.json \
  docs/trinity-power-users-rbac.md \
  registry/auth/dependencies.py 2>/dev/null | head -10 && echo "none" || true
```

3. To apply the formatting fix suggested by Ruff, you can run the `ruff format` command on the specific file. After formatting, it's important to confirm that the code still compiles and retains its intended logic. You can use Python's built-in `py_compile` module to check for syntax errors. Finally, you can use `git diff` to see what changes were made by the formatter.

```bash
# Apply the formatter fix
$ uv run ruff format registry/auth/dependencies.py

# Confirm the formatted result still compiles and has the right logic
$ uv run python -m py_compile registry/auth/dependencies.py && echo "Syntax OK"
```

4. The following commands run a series of checks including linting, formatting, syntax checking, running a subset of tests related to permissions, rendering Helm templates, and running Helm unit tests. Each step provides feedback on whether it passed or failed.

```bash
$ # Run the full pre-commit suite on our changed files only (faster than --all-files)
echo "=== ruff (linter + formatter) ===" && uv run ruff check registry/auth/dependencies.py && uv run ruff format --check registry/auth/dependencies.py && echo "PASS"

$ echo "=== python syntax ===" && uv run python -m py_compile registry/auth/dependencies.py && echo "PASS"

$ echo "=== pytest fast (permission-related subset) ===" && uv run pytest tests/ -k "permission or ui_permission or has_ui_permission" -q --no-header 2>&1 | grep -E "passed|failed|Tests:"
```
